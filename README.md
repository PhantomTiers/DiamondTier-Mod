# DiamondTier Tags (Fabric, Minecraft 1.21.11)

Shows a player's DiamondTier tier in front of their name above their head, e.g. `HT1 | Name`.
It downloads your site's players.json every few minutes, so rankings update by themselves.

Config file (created on first launch): `config/diamondtier.json`
- url: the link to your players.json
- mode: overall (best tier) or crystal, sword, axe, mace, nethpot, uhc, dsmp, smp
- refreshMinutes: how often to re-download
